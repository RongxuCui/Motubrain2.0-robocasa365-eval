# PolicyServer (model inference) — pip requirements.
#
#   pip install -r requirements-policy.txt
#
# All public packages; this bundle needs no proprietary kernel packages.
#
# Versions are pinned to the environment these were verified in (Python 3.13):
# every module on the inference path imports, the policy config loads, and the
# model builds with a state dict matching the checkpoint. The end-to-end GPU
# evaluation ran on a sibling image of the same environment carrying PyTorch
# 2.12, so both 2.9 and 2.12 are known to work.
#
# torch is pinned by version but not by CUDA build. The verified environment
# had `2.9.1+cu130`, where the `+cu130` local tag comes from PyTorch's own
# index rather than PyPI, so pinning it here would only resolve for people
# installing from that index with a CUDA 13.0-capable driver.
#
# The plain pin below takes the default CUDA build from PyPI, which is what
# most setups want. To reproduce the verified build exactly:
#
#   pip install torch==2.9.1 --index-url https://download.pytorch.org/whl/cu130
#
# torch 2.12 was also exercised end to end; 2.4 is the floor, for
# torch.nn.RMSNorm. `triton` is intentionally absent: the Linux torch wheels
# carry it, and a separate pin can conflict with the chosen torch build.
torch==2.9.1
